## F. 验收矩阵

结果用：通过 / 失败 / 未验证 / 不适用。禁止用“已部署”代替“已验证”。

| 范围 | 操作与检查点 | 桌面结果 | 手机结果 | 本轮证据/问题 |
|---|---|---|---|---|
| 品牌 | 配色字体、对比度、无其他品牌残留 | | | |
| Header | 主导航唯一、菜单/搜索/购物车入口 | | | |
| 首页 | 真实商品、价格、全部 CTA 去向 | | | |
| 商品卡 | 单图/多图 hover、标题与价格无覆盖 | | | |
| PDP | 缩略图/箭头/滑动、缩放、图片无裁切空洞 | | | |
| 变体 | 选择后价格/主图/可售变化 | | | |
| 购物车 | 数量、正确 variant、ATC、结账入口 | | | |
| 页脚 | logo、社媒链接、无运维文案与重复列 | | | |
| 内容 | 政策内容、联系表单、FAQ/指南链接 | | | |
